# Sukoon 🌿

### AI-Powered Student Mental Wellness Platform

Sukoon is a student-focused mental wellness platform designed to help students manage stress, improve emotional well-being, practice mindfulness, and access supportive resources in one place.

## ✨ Features

* 🧠 AI-powered mental wellness support
* 🌿 Guided breathing and mindfulness exercises
* 💭 Mood checking
* 👥 Student community
* 🩺 Therapist support
* 📊 Personal wellness dashboard
* 🚨 Crisis support resources
* 💬 AI wellness assistant

## 🛠️ Tech Stack

* React
* Vite
* JavaScript
* CSS
* GitHub Pages
